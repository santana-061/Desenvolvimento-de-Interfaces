Atividade prática — JavaScript

Aula 2: entrada de dados, DOM, eventos e estruturas condicionais

Objetivo

Praticar a leitura de dados com .value, a localização de elementos com getElementById(), eventos com addEventListener(), conversão com Number() e decisões com if, else if e else.

Preencha os campos e clique nos botões para testar cada atividade.

Laboratório 1 — Verificador de idade

Informe uma idade inteira entre 0 e 120. O programa verifica se a pessoa é maior ou menor de idade e trata entradas inválidas.

Laboratório 2 — Calculadora de média

Digite três notas entre 0 e 10. Média maior ou igual a 6: aprovado. Média abaixo de 6: recuperação.
